Slate: an ultra-minimal Chromium-based browser

View the code
Published
GitHub, 28 December 2025

Summary

A desktop browser built with Qt 6 and Chromium that keeps no history, bookmarks, cookies, or cache. Connections are upgraded to HTTPS, ads and trackers are blocked natively, permissions are denied by default, and the interface is only tabs and an address bar.
